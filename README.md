# what2eat
上班族、学生党等群体每日面临的高频困扰之一便是 “吃什么”—— 外卖平台品类繁杂难以抉择、线下店铺口碑参差不齐、周边隐藏美食难以发掘，导致大量时间浪费在决策上，甚至因选择失误影响饮食体验。 缺乏真实用户的即时性、场景化分享（如 “下雨天适合吃的热汤面”“加班时快速饱腹的轻食”）；而社交平台的美食内容分散，难以精准关联 “用户当前位置” 和 “即时饮食需求”。 ​ what2eat 项目旨在搭建一个聚焦 “即时饮食决策” 的垂直社区：用户通过分享真实用餐体验（附文字、图片、定位等信息），为身边或同场景下的人提供 “吃什么” 的参考，同时通过互动交流规避 “踩雷”，最终形成 “真实、本地、即时” 的美食决策支持社区，解决选择困难症群体的饮食决策痛点。
